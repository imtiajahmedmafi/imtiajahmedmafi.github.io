## 📂 এই ফোল্ডারের ফাইলসমূহ (`E:\imtiaj_protfolio\`)

```text
E:\imtiaj_protfolio/
│
├── index.html        <-- মূল ওয়েবসাইট (ডাবল ক্লিক করলেই চলবে!)
├── style.css         <-- ডিজাইন ও গ্লো ইফেক্ট
├── script.js         <-- মেন্যু ও কপি ফিচার (বাংলায় সহজ কমেন্টসহ)

└── assets/
    └── resume.pdf    <-- আপনার মূল সিভি (PDF) এখানে পেস্ট করবেন
```

## 🚀 কীভাবে ওয়েবসাইটটি দেখবেন (Preview):

1. আপনার কম্পিউটারের **`E:\imtiaj_protfolio`** ফোল্ডারে যান।
2. **`index.html`** ফাইলটির ওপর মাউস দিয়ে **ডাবল ক্লিক (Double Click)** করুন।
3. সাথে সাথে আপনার Google Chrome, Microsoft Edge বা প্রিয় ব্রাউজারে সাইটটি ওপেন হয়ে যাবে!

## 📝 ভবিষ্যতে কোনো তথ্য কীভাবে এডিট করবেন?

সবকিছু সাধারণ HTML টেক্সট আকারে সাজানো আছে। আপনার কোনো জাভাস্ক্রিপ্ট জানা লাগবে না:

1. **`index.html`** ফাইলটি **Notepad** বা **VS Code** দিয়ে ওপেন করুন।
2. কিবোর্ডে `Ctrl + F` চেপে আপনি যে লেখা বা লিংক পরিবর্তন করতে চান তা খুঁজুন (যেমন: আপনার ইমেইল, ফোন নাম্বার, বা কোনো স্কিল)।
3. লেখাটি বদলে ফাইলটি সেভ (`Ctrl + S`) করে ব্রাউজার রিফ্রেশ করুন!

### ১. নিজের সিভি (PDF) যোগ করার নিয়ম:
* আপনার যে মূল সিভি (PDF ফাইল) আছে, সেটির নাম পরিবর্তন করে রাখুন: **`resume.pdf`**
* এরপর সেই ফাইলটিকে এনে **`E:\imtiaj_protfolio\assets\`** ফোল্ডারের ভেতর পেস্ট করে দিন।
* এতে ওয়েবসাইটের **"Resume"** বাটনটিতে কেউ ক্লিক করলেই আপনার সিভি ডাউনলোড হয়ে যাবে।

### ২. প্রোফাইল ছবি যোগ করার নিয়ম:
* আপনি যদি টার্মিনাল কার্ডের জায়গায় নিজের ছবি বসাতে চান, আপনার ছবির নাম দিন: **`profile.jpg`**
* ছবিটিকে **`E:\imtiaj_protfolio\assets\`** ফোল্ডারে রাখুন।
* এরপর `index.html` ফাইলের হিরো সেকশনে ছবি বসিয়ে নিতে পারবেন।

## 🌐 ফ্রিতে ইন্টারনেটে লাইভ করার নিয়ম (GitHub Pages)

আপনার এই ওয়েবসাইটটি আজীবন ফ্রিতে ইন্টারনেটে লাইভ রাখতে নিচের ৩টি ধাপ অনুসরণ করতে পারেন:

1. [GitHub.com](https://github.com)-এ লগইন করে একটি নতুন রিপোজিটরি (New Repository) তৈরি করুন (যেমন: `portfolio`)।
2. এই `E:\imtiaj_protfolio` ফোল্ডারের সব ফাইল (`index.html`, `style.css`, `script.js`, `assets`) সেখানে আপলোড করে দিন।
3. রিপোজিটরির **Settings** > **Pages** অপশনে যান।
4. **Branch** হিসেবে `main` বা `master` সিলেক্ট করে **Save** দিন।
5. ১-২ মিনিটের মধ্যে গিটহাব আপনাকে একটি ফ্রি লাইভ লিংক দেবে (যেমন: `https://yourusername.github.io/portfolio`), যা আপনি আপনার সিভি বা লিঙ্কডইনে যোগ করতে পারবেন!
